# VV-Lab-104-PSVS

## Project Overview
This repository contains the Software Verification and Validation lab work for the Polar Seed Vault System (PSVS), including baseline requirements, defect taxonomy, defect logging, peer-review records, and summary reporting.

## Objectives
- Establish configuration management and a requirements baseline.
- Inspect informal requirements S1-S12 for defects.
- Classify defects using a documented taxonomy.
- Record cross-requirement findings and severity.
- Compare findings with a classmate's peer review and calculate detection rate.
- Summarize defects with tables and a chart.

## Repository Structure
- `requirements/` — Baseline requirements.
- `defect-logs/` — Taxonomy, defect log, and peer-review comparison.
- `abstractions/` — System abstraction placeholder for later tasks.
- `models/` — System model placeholder for later tasks.
- `operations/` — Operational specification placeholder for later tasks.
- `constraints/` — System constraints placeholder for later tasks.
- `proofs/` — Proof artifacts placeholder for later tasks.
- `reports/` — Defect summary and chart.
- `.github/ISSUE_TEMPLATE/` — Change-request issue template.
